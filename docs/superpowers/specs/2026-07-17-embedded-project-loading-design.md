# 嵌入项目加载修复设计

## 目标

让作品展示页中的公众号编写、好学图书线索访达和跳舞裁剪三个项目在嵌入窗口及独立标签页中都能正常加载，不再出现黑色空白窗口。

## 原因

三个项目位于“AI项目”共同父目录下，但展示页此前只从“作品展示页 2”目录启动静态服务。iframe 的 `../` 引用在该服务器根目录之外，因而返回不存在的资源。

## 方案

1. 使用“AI项目”作为静态服务根目录，展示页访问入口为 `/作品展示页%202/`。
2. 保留 iframe 的相对路径引用，使其在共同根目录下解析到相邻项目。
3. 将三个“新标签页全屏独立运行”链接改为从共同根目录解析的绝对站内路径。
4. iframe 发生加载错误或加载超时时，在窗口内显示明确的故障提示与可重试操作，不再呈现无反馈黑屏。

## 验收

- 三个 iframe 都返回有效页面内容。
- 三个独立链接都可打开对应项目。
- 展示页自身在共同根目录的入口正常加载，刷新按钮仍可重新加载对应 iframe。

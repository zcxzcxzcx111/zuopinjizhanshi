# 首屏与项目页重叠衔接设计

## 目标

消除人物剪影页与项目首页之间的水平硬切和黑色空档，同时保留原有粒子消散、固定导航和上下双向滚动能力。

## 已确认方案：A｜重叠空间转场

- 人物剪影内容放入 `100svh` 的 sticky 舞台，外层提供额外滚动行程。
- 项目首页在剪影舞台结束前约 `20vh` 提前从底部进入，两个页面短暂重叠。
- 项目页顶部增加约 `180px` 的透明至深紫黑羽化带，隐藏两层边界。
- 使用 `smoothstep` 将原始滚动进度转为视觉进度，人物、粒子、标题和项目页同步缓动。
- 向上滚动时同一进度反向播放，不引入锁滚或不可逆状态。

## 动效节奏

1. `0%–40%`：剪影保持主体地位，粒子开始从边缘消散。
2. `40%–78%`：项目页顶部提前上移，羽化带覆盖页面边界。
3. `78%–100%`：项目标题进入最终位置，剪影和粒子退场完成。

## 性能与无障碍

- 仅动画 `transform`、`opacity` 和 Canvas 绘制，不逐帧修改布局尺寸。
- 滚动读取和样式写入统一放在 `requestAnimationFrame`。
- `prefers-reduced-motion` 下关闭粒子与位移动画，保留正常文档流。
- 移动端缩短重叠距离，避免小屏出现过长粘滞区。

## 验收标准

- 下滑与上滑都看不到横向黑色断层。
- 导航栏全程固定且始终可点击。
- 项目页在剪影完全退出前已可见，最终位置不发生跳变。
- 粒子效果仍可逆，快速滚动时无明显闪烁或布局抖动。

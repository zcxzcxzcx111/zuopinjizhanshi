# 第三个项目预览区高度调整设计

## 目标

压缩“单人锁定裁剪”项目预览区中标注位置的上下空白，使右侧预览与左侧操作内容的底部基本齐平，并减少左侧栏底部被整体页面高度拉长形成的空白。

## 方案

- 采用用户确认的 B 方案。
- 仅修改作品展示页中 `#iframe-video` 的固定高度。
- 将高度从 `1460px` 调整为 `1060px`。
- 不修改“跳舞裁剪”子项目内部的网格、视频舞台、侧栏或交互逻辑。
- 不影响另外两个项目的 iframe 高度。

## 预期效果

- 第三个项目的整体展示高度减少约 400px。
- 视频舞台上下空白明显缩减。
- 左右两栏底部视觉上基本齐平。
- 裁剪框、时间轴及左侧操作按钮仍完整可见。

## 验证

- 检查 `#iframe-video` 的计算高度为 `1060px`。
- 打开作品展示页，确认第三个项目没有内部纵向滚动条。
- 确认视频舞台、时间轴和左侧操作区没有被裁切或重叠。
- 确认前两个项目的展示高度和布局不变。

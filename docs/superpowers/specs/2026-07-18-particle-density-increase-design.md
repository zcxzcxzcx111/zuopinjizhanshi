# 粒子密度 A 档调整设计

## 目标

让首页人物剪影在消散、流向左侧光源和汇入光场时更饱满，同时保持现有运动方向、颜色比例、消散节奏和双向滚动还原逻辑不变。

## 参数调整

- 桌面端粒子上限由 `9000` 提升至 `14000`。
- 移动端粒子上限由 `3500` 提升至 `5000`。
- 桌面端采样间距由 `6px` 缩小至 `5px`。
- 移动端采样间距由 `9px` 缩小至 `7px`。
- 保留现有确定性抽样、二次贝塞尔流向、紫白光吸附和反向滚动重建算法。

## 性能边界

- 继续按桌面端和移动端分别设置硬上限，避免高分辨率图片生成不受控的粒子数量。
- 不新增常驻动画循环；仅在滚动进度变化时通过现有绘制路径刷新。
- 保留设备像素比最大值 `2`，避免高 DPI 屏幕造成额外画布开销。
- 不增加粒子尺寸和光晕强度，避免密度提升后画面发灰或遮挡第二页文字。

## 交互与视觉

- 首屏静止状态仍显示完整人物剪影。
- 下滑后粒子数量明显增加，但整体轮廓和流向仍可辨认。
- 粒子最终继续汇入第二页左侧紫白光源，不改变页面衔接时序。
- 上滑返回时，新密度粒子按相同路径逆向恢复，最终重新显示完整剪影。

## 验证标准

- 合约测试锁定桌面端 `14000`、移动端 `5000` 和采样间距 `5/7`。
- JavaScript 语法检查通过。
- 桌面端检查中段消散密度、最终融光和反向还原。
- 移动端确认无横向溢出，滚动衔接与粒子恢复正常。
- 页面控制台不出现本次修改引入的新错误。

# 人物剪影滚动粒子消散设计

## 目标

人物剪影首屏向下进入项目页时，剪影从轮廓边缘开始转化为粒子并向左上方漂散；向上返回首屏时，粒子沿原路径反向聚合成人物剪影。固定导航、竖排标题和项目页内容不参与消散。

## 方案

使用原生 Canvas 2D，不增加第三方依赖。加载 `assets/hero-portrait-silhouette.png` 后，在离屏画布按透明度采样人物像素，生成带有原始坐标、漂移方向、旋转相位和延迟的粒子数据。可见画布与人物图片使用同一定位容器，保证不同屏幕尺寸下轮廓一致。

## 滚动阶段

粒子效果读取正式页面已有的 `--portrait-progress`：

1. `0.00–0.12`：完整剪影保持稳定。
2. `0.12–0.72`：从人物外轮廓向内部逐步消散，原图同步降低透明度。
3. `0.72–1.00`：剩余粒子继续漂移并淡出，项目页完成进入。

向上滚动时使用相同进度反向绘制，因此粒子自然回到采样位置，不建立第二套动画状态，也不会与双向滚动控制冲突。

## 粒子表现

- 粒子以 1–3px 的紫黑色微粒为主，少量粒子带低亮度紫色边缘。
- 漂移方向以左上方为主，并加入确定性的轻微横向扰动；重复往返时轨迹一致。
- 每个粒子按其原始位置计算延迟，优先消散头发、肩部和衣服外缘，再逐渐进入主体。
- 不添加爆炸闪光、发光门或大面积光晕，保持克制的编辑型视觉质感。

## 性能与适配

- 桌面端采样步长约 6px，粒子上限 9,000；窄屏采样步长约 9px，粒子上限 3,500。
- Canvas 按设备像素比绘制，但 DPR 上限为 2。
- 仅在剪影首屏处于视口附近且进度发生变化时绘制；其余时间停止动画帧。
- 窗口尺寸变化后重新计算画布与采样坐标。
- `prefers-reduced-motion: reduce` 时关闭粒子漂移，仅使用剪影透明度过渡。
- 图片加载或 Canvas 初始化失败时保留原剪影，不影响页面浏览与双向滚动。

## 可访问性

Canvas 标记为装饰元素并设置 `aria-hidden="true"`。原人物图片继续保留替代文本；粒子启用时只改变其视觉透明度，不删除语义节点。

## 验收标准

- 下滑时剪影连续粒子化，不出现整块突然消失或黑屏。
- 返回时粒子准确聚合，最终恢复完整人物剪影。
- 导航栏始终固定，竖排标题在转场前保持清晰。
- 连续往返三次无粒子累积、闪烁或明显掉帧。
- 390px 窄屏可用，减少动态效果设置下无漂移动画。

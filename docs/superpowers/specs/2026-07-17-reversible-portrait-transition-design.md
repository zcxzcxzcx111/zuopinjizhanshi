# 人物剪影页双向滚动转场设计

## 目标

首屏人物剪影页向下滚动后自然进入项目内容页；进入项目页后，只要项目页已经位于顶部，用户继续向上滚动即可平滑返回人物剪影页。

## 交互规则

- 剪影页向下滚动时，项目页自底部连续覆盖进入，不出现黑屏、空白帧或重复页面。
- 项目页内部存在滚动距离时，向上滚动只负责正常回到项目页顶部，不提前触发返回。
- 项目页位于顶部后，再次产生明确的向上滚动意图才开始返回剪影页。
- 返回过程中锁定重复触发，避免滚轮惯性导致页面来回跳动。
- 返回完成后恢复首屏正常滚动，可再次向下进入项目页。
- 鼠标滚轮与触控板使用同一套方向和阈值判断；键盘 Escape 保留为调试和无障碍返回方式。

## 状态设计

转场仅使用三个状态：

1. `intro`：剪影首屏可见，滚动进度控制项目页上移。
2. `entered`：项目页完全覆盖并接管交互。
3. `returning`：项目页退出、剪影页恢复；完成前不允许再次进入。

原型中的项目页通过同源 iframe 展示，因此在 iframe 内监听滚动位置和向上滚轮意图。正式项目使用真实 DOM 上下衔接，不依赖 iframe，浏览器原生滚动即可天然支持双向返回。

## 防误触

- 只有项目页滚动位置小于等于 8px 时才累计返回意图。
- 顶部向上滚动累计超过小阈值后才触发，过滤触控板轻微抖动。
- 一旦出现向下滚动或项目页离开顶部，立即清空累计值。
- 转场动画进行中忽略新的进入或退出请求。

## 视觉与性能

- 返回时沿用进入动画的反向运动，项目页整体向下退出，剪影、竖排标题和背景同步恢复。
- 仅动画化 `transform` 与 `opacity`，避免布局抖动。
- 尊重 `prefers-reduced-motion`：减少过渡距离并关闭平滑滚动。

## 验收标准

- 连续下滑进入项目页时中间没有黑屏。
- 在项目页任意位置上滑不会误退；到顶部后继续上滑才返回。
- 返回剪影页后可再次进入项目页，至少连续往返三次不出现卡死或跳页。
- 桌面鼠标滚轮、触控板与移动端窄屏布局均保持可用。

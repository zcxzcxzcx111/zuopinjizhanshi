# 人物剪影粒子融入左侧光场转场设计

## 目标

让作品集第一页的人物剪影自然过渡到第二页。剪影不直接淡出，也不在页面交界处形成黑屏；它应分解为定向粒子，粒子被第二页左侧紫白光场吸收，最终成为该光场的一部分。

本设计采用已确认的 **A｜流场吸附** 方向，并采用“粒子刚开始消散，第二页就提前露出”的衔接节奏。

## 视觉叙事

第一页的人物是被压缩的“能量主体”。用户下滑后，能量从人物外轮廓松动，形成沿左下方向流动的粒子尾迹。第二页同时从底部进入。粒子接近第二页左侧时减速、变亮并逐步失去颗粒边界，最终扩散成现有背景里的紫白纵向柔光。

整个过程表达的是“人物能力转化为项目成果”，而不是简单删除人物。

## 转场时间线

### 0%–18%：轮廓预热

- 人物剪影保持完整。
- 仅头发、肩部和背部外缘出现少量 1–2px 微粒。
- 标题与竖排身份信息轻微降低亮度，但不移动出画面。
- 第二页尚未成为主要视觉，只在底部出现极弱的紫色环境光。

### 18%–48%：粒子剥离与第二页提前进入

- 粒子从人物外轮廓向左下方剥离，内部区域随后跟进。
- 粒子运动采用弧形流线，不做均匀直线或爆炸式扩散。
- 第二页从视口底部提前进入，进入量约为 12–20vh。
- 第二页标题保持较低对比度，避免与人物同时争夺焦点。

### 48%–68%：粒子入流

- 人物主体快速降低不透明度，只保留少量结构性暗粒子。
- 粒子接近左侧光区后速度降低，尺寸从 1–3px 过渡到 3–8px 的模糊光斑。
- 粒子颜色从深靛蓝过渡到紫色，再由少量高亮白粒子引导视觉。
- 第二页标题与卡片逐步进入最终位置。

### 68%–100%：光场接管

- 粒子完全失去独立颗粒边界，合并为左侧紫白柔光。
- 柔光范围与第二页现有背景光区一致，不额外生成新的独立光团。
- 第一页竖排标题与剪影完全退出。
- 第二页内容达到正常亮度与最终位置。

## 粒子设计

### 形态

- 80% 为深靛蓝小方点或圆点，尺寸 1–2px。
- 15% 为紫色粒子，尺寸 1–3px。
- 5% 为高亮白粒子，仅用于尾迹和光场边缘，避免形成烟花感。
- 粒子靠近光场后增大模糊半径，而不是简单放大实体尺寸。

### 运动

- 初始速度由人物轮廓法线向外，再被左下方向的流场吸引。
- 运动路径带轻微正弦扰动，形成空气流动感。
- 不使用随机全方向爆炸，不让粒子飞出视口右侧。
- 粒子进入光区时采用减速曲线，防止在接缝处突然消失。

### 光场融合

- 光场由低频大范围的径向渐变、纵向光栅和粒子模糊叠加组成。
- 粒子融入光场后继续保留极低密度的漂浮细点，使能量来源可被感知。
- 光场最大亮度保持在标题左侧，不覆盖正文卡片的可读区域。

## 页面衔接

- 第一页使用 sticky 舞台提供连续滚动行程。
- 第二页在进度约 18% 时开始从底部进入，并与第一页重叠。
- 两页交界处使用 160–220px 的羽化区消除水平接缝。
- 第二页的上移、透明度和光场亮度均由同一个平滑滚动进度驱动。
- 固定导航栏全程保持在最上层，不参与粒子消散。

## 双向滚动

转场必须完全可逆。向上回滑时：

1. 第二页内容向下退出；
2. 左侧光场收束为模糊粒子；
3. 粒子沿原路径反向回流；
4. 粒子重新聚合成人物剪影；
5. 竖排标题恢复完整亮度。

任何方向都不使用一次性锁定状态，避免回到顶部时出现黑屏或人物无法重组。

## 技术边界

- 延续现有 Canvas 粒子系统与 `requestAnimationFrame` 滚动驱动，不增加第三方动画依赖。
- 每帧只更新 Canvas、`transform`、`opacity` 和 CSS 自定义属性。
- 桌面端粒子上限为 9,000，窄屏端上限为 3,500。
- 采样数据在图片加载或视口尺寸变化时重建，不在每次滚动中重新读取像素。
- 页面失焦或转场不可见时停止不必要的持续绘制。

## 响应式与无障碍

- 窄屏端缩短粒子尾迹，减少横向位移，保持光场在标题背后而非正文上方。
- `prefers-reduced-motion` 下关闭粒子流动，以人物短淡出与第二页短淡入替代。
- Canvas 标记为装饰内容，不进入无障碍树。
- 页面原有文案、导航链接和项目内容不因转场改变。

## 验收标准

- 首次下滑时，第二页在人物开始消散后立即可感知地进入。
- 页面交界处没有黑屏、硬横线或整块纯色跳变。
- 粒子方向明确指向左侧光区，不呈现无方向爆炸。
- 粒子在消失前完成“点 → 模糊光斑 → 柔光”的连续变化。
- 向上回滑能够完整还原人物剪影与竖排标题。
- 快速滚动、连续反向滚动和窗口尺寸变化时无明显闪烁或布局跳动。
- 固定导航栏始终可见且可交互。
